# 调度员界面说明与演示脚本

```bash
streamlit run app/streamlit_app.py
```

界面只负责展示和把点击转成 `desk/pipeline.py` 里的调用。所有交期、成本、排序都来自 `kernel/`，界面自己不算任何数字。

## 页面结构

| 位置 | 内容 | 对应的评分点 |
|---|---|---|
| 左侧栏 | 目标选择、解析器选择、载入收件箱、重置、**常驻约束**（谁下的、在哪条消息、可解除）、各车间当前队列 | 目标即配置；约束记录下达人 |
| Dispatch · 左半 | 四个计数（待确认、待决定、待追问、已派出）、按"下一步"排序的收件箱、新消息输入框 | 调度员在压力下先看要处理的 |
| Dispatch · 右半 | 请求卡片：原文、解析结果、**一行结论**、解释、数字核查标记、候选车间对比表、不合格车间及原因、操作按钮、工具调用明细 | 候选、估算、推荐一眼可见；解释可追溯 |
| Workshops | 车间登记册、当前队列图、"谁能接这批"查询 | 可查询的车间登记册 |
| Audit log | 账本记录、所有人工操作记录、下载 audit.json | 可审计的结构化记录 |
| Simulator | 官方模拟器实时运行：三个 baseline、十行启发式、五种目标配置，可切换 seed 和 shock | 与 baseline 对比 |
| Dev check | 与标准答案草稿对照，需要勾选"已交独立分类"才显示 | 开发自检，不是评估 |

## 请求卡片的一行结论

| 情况 | 颜色 | 按钮 |
|---|---|---|
| 有按时方案 | 绿 | 确认推荐车间；或从下拉框选别家 |
| 没有按时方案 | 橙 | 接受延误并派出；或选别家；重谈交期；上报 Boss |
| 指定了不能接的车间 | 红 | 用替代车间派出；或选别家 |
| 需要追问 | 蓝 | 复制追问话术；指代不清时直接选订单；输入请求人的回答让系统重新处理 |
| 数据里没有答案 | 灰 | 复制回复话术；标记已回复 |
| 已派出 | 紫 | 改派；查看审计记录 |

确认时系统会用**当前账本**重新估算一次。别的请求先确认了、队列变了，卡片会标出"updated since received"。晚交的派单必须明确点"接受延误"才会写入账本。

## 5 分钟演示脚本（Sprint 2 视频可直接用）

1. **载入收件箱。** 讲一句：30 条群聊进来，系统没有派出任何一单，只是分好了类。指着四个计数说明哪些要确认、哪些没有按时方案、哪些要追问。
2. **R09，正常派单。** 一行结论是 Nimble Needle 按时。展开候选表，说明排队、加工、返工期望、运输四个分量。点确认，计数变化，审计号出现。
3. **R12，前面的派单改变了后面的答案。** 讲 R09 占用 Nimble Needle 后，R12 的推荐变成 GiantWeave。指左侧栏的约束：QuickStitch 本周不接新单，Boss 在 R12 下达。
4. **R21，没有好选择。** 橙色：没有车间能按时，最早晚 1 天。解释里写着"如果解除对 QuickStitch 的禁令，可以按时"。点左侧 Lift，R21 变成绿色。讲这就是"把决定权交还给人"。
5. **R08，拒绝。** FreshStart 单批上限 300，请求是 400 件。系统给出替代并可一键派出。
6. **R03，追问。** TrendCart 有 6 单在途，系统列出候选而不是猜。直接选订单，新请求自动生成。
7. **R18，无法回答。** ORD-999 不存在，系统说查不到，不编。
8. **Audit log。** 展示每一次确认、改派、解除约束都有记录，可下载。
9. **Simulator。** 切 shock，说明 lateness 配置与十行启发式打平，这是我们在报告里如实写的发现。

## 部署成公开 demo 链接

Sprint 2 首页需要可打开的 demo 链接。Streamlit Community Cloud 免费：

1. 用仓库所有者账号登录 https://share.streamlit.io ，授权读取 GitHub。
2. New app，仓库选 `dss5105-track2/track2-desk`，分支 `main`，入口文件 `app/streamlit_app.py`。
3. 部署。默认使用规则解析器，不需要任何密钥。
4. 如果要在线演示 GPT-5 nano：在应用的 Settings → Secrets 里填 `OPENAI_API_KEY`，并先在 OpenAI 后台设好支出上限。**不要把 key 写进仓库。**

公开链接意味着任何人都能点确认。会话之间互不影响，刷新页面或点 Reset 就回到初始状态。
